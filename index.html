ForClaude 廣告報表工具

ForClaude 廣告報表工具是在使用者自己電腦上執行的程式，協助數位廣告操作人員整理 Google Ads 廣告成效報表，並在使用者確認後更新 Google Ads 廣告設定。本頁公開，任何人不需登入即可瀏覽。

應用程式用途

  • 廣告成效報表：讀取使用者有權限的 Google Ads 帳戶成效數據（曝光、點擊、花費、轉換）與 Google Analytics 報表，整理成週報、月報。
  • 廣告管理：經使用者逐次確認後，在使用者有權限的 Google Ads 帳戶建立廣告、暫停或開啟廣告、調整每日預算。所有變更都先以試跑（validate only）檢查，使用者同意後才正式寫入。
  • Google 試算表：讀取使用者指定的試算表（廣告需求表、文案表），並把報表數字寫回使用者指定的試算表。
  • Google 雲端硬碟：唯讀下載使用者指定資料夾裡的廣告圖片素材。
  • Gmail：用使用者本人的 Gmail 寄送執行結果通知給使用者自己。

使用方式

使用者以自己的 Google 帳號授權後，程式只存取該帳號原本就有權限的資料。授權憑證只存在使用者自己的電腦，可隨時到 Google 帳戶的第三方存取權 撤銷。

遵循 Google API 服務條款

本工具遵守 Google API 服務條款 與 Google API 服務使用者資料政策（含「有限使用」規定）。本工具不使用任何 Google API 產生圖片、影片或 AI 生成內容，也絕不用於製作或散布未經同意的私密影像（NCII）。透過 Google API 取得的資料不會出售、不會提供給第三方，也不會用於訓練 AI 模型。

English

ForClaude 廣告報表工具 (ForClaude Ad Reporting Tool) is a desktop program that runs on the user's own computer. It helps digital advertising operators build Google Ads performance reports and, after the user reviews each change, update their Google Ads campaigns. This page is public and can be viewed without signing in.

What the app does

  • Reporting: reads performance data (impressions, clicks, cost, conversions) from Google Ads accounts and Google Analytics reports the user already has access to, and compiles weekly and monthly reports.
  • Campaign management: after the user approves each change, creates ads, pauses or enables ads, and adjusts daily budgets in those Google Ads accounts. Every change is first checked with a validate-only request.
  • Google Sheets: reads the user's own planning sheets and writes report figures back to sheets the user chooses.
  • Google Drive: read-only download of ad image assets from folders the user chooses.
  • Gmail: sends job-result notifications from the user's own Gmail to the user.

Compliance: the app complies with the Google APIs Terms of Service and the Google API Services User Data Policy, including the Limited Use requirements. It does not use Google APIs to generate images, video or any AI-generated content, and is never used to create or distribute non-consensual intimate imagery (NCII). Data obtained through Google APIs is not sold, not shared with third parties, and not used to train AI models.
