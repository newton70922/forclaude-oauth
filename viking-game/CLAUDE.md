# 北境雄心：協作規則

## 溝通

- 一律用繁體中文回覆。

## 工作流程（使用者指定，每次都照做）

1. 使用者給回饋後，**先評估、不動作**：
   - 說明現況和原因。
   - 給出建議；有更好的做法就直接提出來。
   - 列出需要使用者決定的地方。
2. 使用者確認後，才動手修改。
3. 改完之後的步驟：
   - 測試。
   - commit 並 push 到指定分支。
   - 發布到同一個 artifact。
   - 用繁體中文回報。
4. **唯一例外**：使用者明確說「直接做」，才可以跳過評估、直接動手。

## 遊戲裡的提示

- 隱藏機制不要在遊戲裡寫出說明文字（例如：被騙兩次後，下一招一定看得清楚）。

## 小遊戲

- 解謎型的小遊戲**不能有時間倒數壓力**，只有反應型才有計時。

## 圖片與劇情

- 放新圖時，要檢查圖和文字、前後頁的順序是否合理（例如劍掉在地上的圖，不能接在「用劍撐地」之前）。發現不合理的地方，要主動告訴使用者。
