# 系統盤點（2026-11-27）

這份是把遊戲目前所有的系統攤開來看：每個在做什麼、跟誰連動、我的判斷。
只是盤點和建議，**沒有改任何東西**。

## 一、規模

- 程式約 7,600 行（約 900 KB），圖約 640 張，還有 99 張沒畫、24 張要重畫。
- 四章：漁村 → 部落 → 挪威 → 王的歲月，加上多種結局（諸神黃昏、斯蒂克萊斯塔、附庸、失國……）。
- 小遊戲 12 種：單挑、部隊戰三回合、盾牆、國王棋、摔角、擲斧、冰釣、雪地追蹤、山羊、秤銀、連擊、覺醒老王。

## 二、系統清單

標記：**核心**＝這個遊戲的靈魂；**連動弱**＝做得完整，但跟其他系統幾乎沒有互相影響；**重疊**＝和別的系統在做差不多的事。

### 角色本身

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 四項能力（力量、體魄、智謀、威望） | 選項成功率、戰力、小遊戲加成 | 有用，但大多只是「機率 +幾 %」，玩家感覺不到差別 |
| 等級、經驗、天賦樹、精通 | 升級點天賦 | **重疊**：天賦和能力都在加成功率 |
| 生命、傷疤 | 單挑和親自上陣會受傷 | 好，傷疤會留下來是有記憶感的設計 |

### 資源

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 銀幣、糧食 | 蓋房子、招兵、各種花費 | **壓力不夠**：你的截圖裡，第 16 年銀 1,711、糧 1,049。中後期幾乎不會缺，所以「要不要花」不再是決定 |
| 戰士（一般、老兵、精兵） | 戰力、傷亡 | 好，打仗會死人是真實的代價 |
| 名聲、惡名、忠誠 | 名聲開事件和花用；惡名引來討伐；忠誠影響叛亂 | **重疊**：三條都在量「別人怎麼看你」，玩家很難同時記住 |

### 部落與國家

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 部落建設（建築、住房、分贓政策） | 加成、容量 | **連動弱**：蓋完就忘了 |
| 季節活動（春耕、夏至、收成祭、冰上捕魚） | 季節限定的行動 | **連動弱**：有氣氛，但大多是「換一點資源」 |
| 天氣 | 影響出海、收成 | 好的調味料，不用動 |
| 地圖征服（區域、雅爾單挑、結盟） | 第三章的主線 | **核心**：跟宿敵、勇士都有連動 |
| 第四章的國事：國法、冊封雅爾、海外遠征、丹麥警戒、叛亂、婚事、繼承人 | 當王之後的各種事 | **太多條線同時跑**：每條都完整，但同一時間要顧七件事，哪件都不深 |

### 勇士（遊戲最有辨識度的部分）

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 招募、好感 | 收勇士、累積感情 | **核心** |
| 立誓、心事任務、覺醒 | 每個勇士的個人故事線 | **核心**：你最常回饋的地方，也是玩家最記得的 |
| 搭檔與和好事件 | 勇士之間的關係 | 好，但觸發條件玩家看不到 |
| 派勇士出任務 | 勇士離開幾季，回來帶結果 | 好，讓勇士「不只會打架」 |
| 部隊戰：打頭陣、勇士出手、本場最佳 | 勇士在戰鬥裡的作用 | **重疊**：一場仗裡有三種「勇士上場」的方式 |
| 決鬥代理人 | 勇士替你單挑 | 好，會死人，有份量 |

勇士底下有九個小系統，各自都對，但加起來玩家很難看懂「我跟這個人的關係走到哪裡了」。

### 信仰與神話

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 神恩（奧丁、索爾、提爾、弗蕾亞、洛基）、布洛特祭 | 祭祀換加成；諸神黃昏時神會來幫你 | 好，有收尾。中途的加成玩家感覺不到 |
| 受洗與十字架 | 換貿易，失去神的眷顧 | **核心**：通往斯蒂克萊斯塔，選擇有份量 |
| 洛基的來訪、芬布爾之冬、諸神黃昏 | 最後的大事件 | **核心**：遊戲的高潮 |

### 劇情串連

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 宿敵赫羅爾夫 | 從碼頭一路到紅帆營 | **核心**：「事情會回來找你」的最好例子 |
| 修士艾瑟斯坦 | 你怎麼待他，他就變成什麼人 | **核心**：同上 |
| 長屋故事、勇士回響（戰前會議、結局） | 把你做過的事講回給你聽 | **核心**：遊戲會記住你 |
| 名人來訪、懸賞、尋寶、尋找奧德 | 支線 | 有趣，但跟主線沒有連起來 |

### 遊戲外

| 系統 | 在做什麼 | 判斷 |
|---|---|---|
| 出身、傳承、通關記號 | 讓人想再玩一次 | 好 |
| 圖鑑、名人堂、檢查點、選擇紀錄 | 收集、重來、統計 | 好；選擇紀錄還沒拿來分析 |

## 三、我看到的三個結構問題

1. **資源沒有壓力**。中後期錢和糧都用不完，所以大部分「花 X 銀幣」的選項不再是決定。
2. **同一件事有好幾套系統在做**。三條聲望值；能力和天賦；一場仗裡三種勇士上場方式。玩家要記的東西多，每一個的手感卻都變淡了。
3. **第四章太寬**。當王之後同時有七條線，每條都要顧，所以每條都沒時間變深。你最近回報的「順序不對、時機不對」，很多都發生在這一章，這通常是線太多的徵兆。

## 四、建議（由小到大）

**不動架構就能做的**
- 銀幣和糧食的收入調低，或讓冬天真的會吃掉糧食，讓花錢重新變成決定。
- 名聲、惡名、忠誠合成兩條：「名聲」（外人怎麼看你，可以是受人敬重，也可以是讓人害怕）和「人心」（自己人跟不跟你）。
- 勇士的九個小系統，整理成一條看得見的羈絆進度：相識 → 信任 → 立誓 → 心事 → 覺醒。玩家打開勇士頁就知道走到哪了。
- 小遊戲留最有特色的四、五種（單挑、部隊戰、盾牆、國王棋、出海），其他改成一般事件。

**要動一點架構的**
- 第四章收斂成兩條主線：「對外」（丹麥和海外）和「對內」（雅爾、國法、繼承）。其他的併進這兩條。
- 部落建設和季節活動併成「長屋」一個畫面：在這裡蓋房子、過節、聽故事、跟勇士說話。

**先查證再決定的**
- 遊戲已經會記錄每一局的選擇。拿這些紀錄來看：
  - 大家在哪一季停下來（流失點）
  - 哪些行動幾乎沒人按
  - 哪些選項九成的人都選同一個（代表沒有真正的兩難）
- 沒人用的就合併或拿掉，比猜測準。

## 五、不該動的

- 勇士的個人故事線（立誓、心事、覺醒、黃昏之後）。
- 「事情會回來找你」的設計：赫羅爾夫、艾瑟斯坦、長屋故事、戰前會議。
- 單挑的「看穿對手」手感。

這三樣是這個遊戲跟別的維京遊戲不一樣的地方。其他的系統，都應該為這三樣服務。
