# 北境雄心：像素單挑角色（43 張）

單挑畫面上方的小舞台用。風格參考試作頁的「A．側面 2 頭身」。

## 怎麼用

1. 每一張都是「共用風格」＋那一張自己的描述。人物用「人物」風格，大型怪物用「大型怪物」風格。
2. **背景一定要是純洋紅色（#FF00FF）**，我會把洋紅色去掉，變成透明背景。不要畫地面、影子或場景。
3. **方向**：主角面向右邊；所有對手面向左邊（兩邊面對面）。
4. 檔名照表格，PNG 就好。我會縮成真正的像素大小，每一格會變成清楚的方塊。
5. 每個角色只要一張待機姿勢；攻擊、受傷的動作由程式做（衝刺、揮動、閃白、震動）。
6. 同一個角色要跟遊戲裡的立繪對得上（例如哈康的眼罩、拉格納的紅鬍子），但不用畫得很細，認得出來就好。

## 共用風格

人物：

```
16-bit SNES-era JRPG side-view battle sprite, pixel art. Chibi proportions (about 2 heads tall), full body, standing in an idle battle stance. Hard pixel edges, no anti-aliasing, no blur, limited palette (about 16 colors), clean 1-pixel dark outline. Drawn as if on a 64×64 pixel grid, then scaled up so each pixel is a crisp square. Solid flat magenta background (#FF00FF) filling the whole image, no ground shadow, no scenery, no text, no border. Square 1:1 image, character centered and filling about 75% of the height.
```

大型怪物：

```
16-bit SNES-era JRPG side-view battle sprite, pixel art. A large boss monster, full body, in a menacing idle pose. Hard pixel edges, no anti-aliasing, no blur, limited palette (about 20 colors), clean 1-pixel dark outline. Drawn as if on a 96×96 pixel grid, then scaled up so each pixel is a crisp square. Solid flat magenta background (#FF00FF) filling the whole image, no scenery, no text, no border. Square 1:1 image, monster centered and filling about 90% of the image.
```
